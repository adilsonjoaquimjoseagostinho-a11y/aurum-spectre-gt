# Aurum Spectre GT — página de portfólio

Página de demonstração (dados e marca fictícios) com rolagem cinematográfica.

## Estrutura
- `index.html` — página completa (HTML, CSS e JavaScript em um arquivo)
- `assets/car/` — quadros do carro girando (WebP)
- `assets/engine/` — quadros do motor (WebP)
- `assets/interior.webp` — imagem do interior

## Como publicar no GitHub Pages (gratuito)
1. Crie um repositório novo no GitHub (ex.: `aurum-spectre-gt`).
2. Faça upload de todo o conteúdo desta pasta, mantendo a estrutura de pastas.
3. Vá em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
4. Em alguns minutos o site fica disponível em `https://SEUUSUARIO.github.io/aurum-spectre-gt/`.

Os textos, preços e dados técnicos são fictícios.
